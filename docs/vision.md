# Visión

Monteiro OS es una plataforma interna para un negocio real de floricultura en Argentina. Su propósito es ir dando soporte, de forma progresiva, a la operación y a las decisiones del negocio.

Con el tiempo debería ofrecer:

- visibilidad operativa;
- gestión de la producción;
- gestión comercial;
- comprensión financiera;
- analítica;
- apoyo a decisiones;
- carga de datos por lenguaje natural y por voz;
- integración con sensores e IoT.

Las personas que usan el sistema al principio son quienes trabajan directamente en el negocio.

**Monteiro OS tiene que evolucionar a partir de requisitos observados en la operación real, no a partir de funcionalidades especulativas.**

El dominio todavía se está descubriendo. Hasta que un proceso esté entendido con quienes lo ejecutan, no se modelan entidades, pantallas ni flujos para ese proceso.
